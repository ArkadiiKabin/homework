# Практика 1. Структуры данных и алгоритмы

Практическая работа по дисциплине «Структуры данных и алгоритмы».
Реализация шести заданий на C++17.

## Задания

1. Операции с массивом
2. Сравнение сортировок (пузырёк, вставки)
3. Вторая лексикографически наибольшая строка
4. Палиндром
5. Количество различных элементов
6. Первое отсутствующее положительное

## Сборка

Компилятор: **g++ (MinGW-w64)**, стандарт **C++17**.

```
g++ -std=c++17 main.cpp -o main.exe
```

## Запуск

```
./main.exe
```

Появится меню с шестью заданиями.

## Файлы

- `main.cpp` — точка входа, реализации `Task1`–`Task6`, меню
- `structfortask.h` — объявления структур
- `tasks.h` — функции `task1()`–`task6()` с тестами
- `task2_table.h` — таблицы для задания 2
