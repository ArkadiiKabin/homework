## Что считать сложностью

n обозначает число элементов массива, L --- длину строки. Время T
описываем через число выбранных операций. Дополнительную память S
считаем без входных данных, но с учётом созданных копий и стека вызовов.
Указывайте случай анализа: лучший, худший или ожидаемый.

O задаёт верхнюю границу роста, Θ --- точный порядок роста.
Асимптотическая оценка не является временем в миллисекундах. В этой
работе сравнение целых чисел и доступ по индексу считаем операциями
O(1).

## Учебный пример из лекции

int linear_search(const int a\[\], int n, int x) {\
for (int i = 0; i \< n; ++i) {\
if (a\[i\] == x) return i;\
}\
return -1;\
}

Функция возвращает индекс первого совпадения или −1. Предусловия: n ≥ 0
и доступны n элементов массива. При n = 0 обращений к элементам нет.
const запрещает менять массив через этот параметр; копия массива не
создаётся.

Для a = {4, 7, 11, 18} вызов linear_search(a, 4, 11) возвращает 2. В
лучшем случае нужна одна проверка, в худшем --- n. Дополнительная память
равна O(1).

# Задание 3 Вторая строка в лексикографическом порядке

Продолжение практики. Обработка повторяющихся значений.

## Условие

Дан массив строк. Найдите вторую лексикографически наибольшую различную
строку. Повторения одной строки не занимают отдельные места. Если
различных строк меньше двух, выведите NONE.

Сравнивайте строки по обычному порядку std::string. Ввод содержит только
строчные латинские буквы a--z. При совпадающем начале более короткая
строка меньше: apple \< apples. Длина сама по себе не определяет
лексикографический порядок.

## Вход и выход

В первой строке дано n, затем идут n непустых строк, каждая на отдельной
строке. Ограничения: 1 ≤ n ≤ 100 000, длина каждой строки от 1 до 100,
суммарная длина не более 1 000 000 символов. Выведите одну строку ---
ответ или NONE.

### Пример

  -----------------------------------------------------------------------
  **Вход**                                        **Выход**
  ----------------------------------------------- -----------------------
  5\                                              date
  apple\                                          
  banana\                                         
  cherry\                                         
  date\                                           
  elderberry                                      

  -----------------------------------------------------------------------

## Граничные случаи

  ------------------------------------------------------------------------
  **Набор строк**                     **Ответ**      **Что проверяем**
  ----------------------------------- -------------- ---------------------
  apple                               NONE           Всего одна строка

  pear, pear, pear                    NONE           Все строки одинаковые

  pear, pear, apple                   apple          Повторы максимума

  apple, apples, apricot              apples         Общий префикс
  ------------------------------------------------------------------------

## Два подхода

1\. Постройте решение через сортировку. Объясните, как пропустить
повторения наибольшей строки.

2\. Постройте решение за один проход, поддерживая два наибольших
различных значения. Опишите состояние до чтения первой и второй
различных строк.

3\. Обозначьте максимальную длину строки через L. Оцените время с учётом
того, что сравнение строк может просматривать до L символов. Укажите,
храните ли вы копии строк или только индексы.

Проверьте, что ответ меньше максимума и что между ними нет другого
различного значения из входа. Для сравнения подходов используйте
одинаковый набор тестов.

# Задание 4 Палиндром

Продолжение практики. Сравнение времени и дополнительной памяти.

## Условие

Дана строка. Учитывайте только латинские буквы A--Z, a--z и цифры 0--9.
Пробелы и остальные знаки пропускайте. Регистр букв игнорируйте.
Выведите YES, если оставшаяся последовательность одинаково читается
слева направо и справа налево, иначе NO.

Ограничиваем ввод печатными символами ASCII и пробелами. Это задача о
латинском тексте, без обработки кириллицы и других символов Unicode.
Пустая строка и строка без букв и цифр считаются палиндромами.

## Вход и выход

Считайте одну полную строку с помощью std::getline. Её длина от 0 до 100
000 символов. Выведите YES или NO. Не удаляйте пробелы оператором \>\>
до обработки строки.

### Пример

  -----------------------------------------------------------------------
  **Вход**                                        **Выход**
  ----------------------------------------------- -----------------------
  A man, a plan, a canal, Panama                  YES

  -----------------------------------------------------------------------

После удаления лишних знаков и приведения регистра получим
amanaplanacanalpanama.

## Граничные случаи

  -------------------------------------------------------------------------
  **Исходная строка**       **Ответ**   **Причина**
  ------------------------- ----------- -----------------------------------
  Пустая строка             YES         Пустая последовательность

  !!!                       YES         Нет учитываемых символов

  0P                        NO          Цифра и буква различаются

  AbBa                      YES         Регистр не влияет

  ab ca                     NO          После обработки получается abca
  -------------------------------------------------------------------------

## Два подхода

1\. Создайте очищенную строку и проверьте её симметрию.

2\. Обойдитесь без очищенной копии: двигайтесь по исходной строке с двух
концов, пропуская лишние знаки.

3\. Сравните худшее время и дополнительную память при длине L.
Объясните, почему одинаковый линейный порядок времени не означает
одинаковые затраты памяти.

Если используете std::isalnum или std::tolower из \<cctype\>,
передавайте символ после преобразования к unsigned char. Не меняйте
локаль при работе с этим ASCII-вводом. Следите за пустой строкой:
выражение size() − 1 для неё опасно из-за беззнакового типа размера.

# Задание 5 Количество различных элементов

Продолжение практики. Выбор способа хранения уже встреченных значений.

## Условие

Дан массив целых чисел. Найдите количество различных значений. Каждое
значение учитывается ровно один раз независимо от числа повторений. Это
отличается от подсчёта значений, встречающихся только один раз.

## Вход и выход

В первой строке дано n, во второй --- n целых чисел. Ограничения: 0 ≤ n
≤ 100 000; −10⁹ ≤ a\[i\] ≤ 10⁹. При n = 0 строка с элементами может
отсутствовать. Выведите одно целое число --- количество различных
значений.

### Пример

  -----------------------------------------------------------------------
  **Вход**                                        **Выход**
  ----------------------------------------------- -----------------------
  6\                                              5
  1 2 3 4 4 5                                     

  -----------------------------------------------------------------------

Различные значения: 1, 2, 3, 4, 5. Повторение числа 4 не увеличивает
ответ.

## Граничные случаи

  --------------------------------------------------------------------------
  **Массив**                          **Ответ**   **Что проверяем**
  ----------------------------------- ----------- --------------------------
  \[\]                                0           Пустой массив

  \[9\]                               1           Один элемент

  \[4, 4, 4, 4\]                      1           Все элементы равны

  \[−1, 0, −1, 2\]                    3           Отрицательные значения

  \[5, 4, 3, 2, 1\]                   5           Все элементы различны
  --------------------------------------------------------------------------

## Сравнение подходов

1\. Реализуйте прямой подход: определяйте, встречалось ли текущее
значение среди предыдущих. Для экспериментов с этим вариантом ограничьте
n числом 2 000.

2\. Реализуйте вариант с предварительной сортировкой, а затем подсчётом
изменений между соседними значениями.

3\. Дополнительно, если изучены хэш-таблицы, реализуйте вариант со
std::unordered_set. Разделяйте ожидаемую оценку и худший случай.

Быстрые подходы проверьте также при n = 100 000. Укажите, меняется ли
вход и учитываете ли его копию в памяти. Какой подход вы выберете при
запрете изменять исходный массив? Обоснуйте выбор с учётом доступной
памяти.

# Задание 6 Первое отсутствующее положительное число

Продолжение практики. Ограничение области поиска.

## Условие

Дан массив целых чисел. Найдите наименьшее положительное целое число,
которого нет в массиве. Повторения, нули и отрицательные значения не
меняют смысл ответа.

## Вход и выход

В первой строке дано n, затем n целых чисел. Ограничения: 0 ≤ n ≤ 100
000; −10⁹ ≤ a\[i\] ≤ 10⁹. При n = 0 строка с элементами может
отсутствовать. Выведите одно положительное целое число.

### Пример

  -----------------------------------------------------------------------
  **Вход**                                        **Выход**
  ----------------------------------------------- -----------------------
  5\                                              4
  1 2 0 -1 3                                      

  -----------------------------------------------------------------------

## Граничные случаи

  --------------------------------------------------------------------------
  **Массив**                          **Ответ**   **Что проверяем**
  ----------------------------------- ----------- --------------------------
  \[\]                                1           Пустой массив

  \[−3, −1, 0\]                       1           Нет положительных

  \[1, 1, 2\]                         3           Повторы не мешают

  \[3, 4, −1, 1\]                     2           Пропуск внутри диапазона

  \[1, 2, 3, 4\]                      5           Нет пропусков до n

  \[1 000 000 000\]                   1           Очень большое значение
  --------------------------------------------------------------------------

## Два подхода и усложнение

1\. Начните с кандидата 1. Для каждого кандидата проверяйте его наличие
полным проходом по массиву. Исследуйте этот вариант при n ≤ 2 000.

2\. Докажите, что ответ находится в диапазоне от 1 до n + 1. Используйте
этот факт для решения с массивом отметок. Обоснуйте время и
дополнительную память.

3\. Дополнительно найдите решение с O(n) временем и O(1) дополнительной
памятью, если разрешено переставлять элементы исходного массива. Этот
пункт повышенной сложности.

В любом варианте сначала проверяйте диапазон значения, и только затем
используйте его как индекс. Для варианта с перестановками отдельно
продумайте дубликаты, чтобы цикл не выполнял один и тот же обмен
бесконечно.
